# PRD — Maternal Nutrition App Theming & UI Refresh

**Project:** “Veggie-Fresh” Design System (Carrot Tops + Beetroot, Herb Tint)
**Owner:** You
**Why now:** Current look skews dated (linen bg + blobby shapes + default grey buttons). We want a modern, warm, trustworthy UI aligned with maternal nutrition.

---

## 1) Objective

Re-theme the existing app without changing flows or IA: apply the **Carrot Tops + Beetroot** palette, adopt **Herb Tint** background, modernize component shapes, and set a clear typography system (Lora for headings; demure humanist sans elsewhere). Preserve performance and pass WCAG AA.

**Success looks like:**

* Visually fresh, consistent app; no default grey HTML buttons anywhere.
* Clear accent hierarchy (carrot primary, lettuce secondary, beet tertiary).
* Readable at small sizes; numbers align cleanly; contrast passes AA.

---

## 2) In Scope

* New theme tokens (colors, radius, borders, spacing).
* Component restyle: buttons, cards/sheets, chips/badges, progress, tabs/nav.
* Typography rules + numeric features.
* Light elevation model (borders > shadows).
* Platform snippets (web/RN, iOS, Android).

## 3) Out of Scope

* New features, flows, IA, or copy.
* Motion design beyond basic pressed/hover/focus.
* New icons or illustration system.

---

## 4) Users & Constraints (relevant to design)

* Pregnant/breastfeeding users tracking nutrients; some may have low vision or older devices.
* Mobile-first. Must feel credible but warm; no “medical coldness” or “kids app” energy.

---

## 5) Design System — Tokens

* **Lettuce (secondary):** `#6FBF4A`
* **Carrot (primary CTA):** `#E77C1F`
* **Beetroot (tertiary emphasis):** `#8E2043`
* **Tan (quiet icons/dividers):** `#B6915E` (use at 30–40% opacity)
* **White (surfaces):** `#FFFFFF`

### 5.2 Backgrounds

* **App Background (Herb Tint):** `#F7FBF7`  ← default
* **Modern Bone (alt theme candidate):** `#FBFAF7`
* (Legacy for reference only: Linen `#F6F3E9`—**do not** ship)

### 5.3 Surfaces & Lines

* **Card/Sheet Surface:** `#FFFFFF`
* **Hairline Border:** `#E0EAE0` (1 px)
* **Progress Track (neutral):** `#E6EEE6`

### 5.4 Accessible States

* **Focus Outline:** 2 px `#183A2E` (or 10–15% darker version of the component fill).

### 5.5 Accent Usage Budget (keep the UI calm)

* Carrot: **5–8%** of pixels
* Lettuce: **8–12%**
* Beetroot: **3–6%**

---

## 6) Typography

### 6.1 Families

* **Headings / Tips / Pull-quotes:** **Lora** (Regular/Semibold).
* **Body / Inputs / Nav / Tables / Small Labels:** **Source Sans 3** (preferred) or **Inter**.
* **Numbers:** tabular lining figures enabled everywhere numbers align.

### 6.2 Type Scale (mobile)

* **H1:** 28–32 / 1.15 (Lora Semibold)
* **H2:** 22–24 / 1.2 (Lora Semibold)
* **H3:** 18–20 / 1.25 (Lora Regular/Semibold)
* **Body:** 16–17 / 1.45 (Sans Regular)
* **Caption:** 13–14 / 1.3 (Sans Regular)
* **Buttons:** 16–17 (Sans Medium/Semibold)

**Tracking:** leave body default; headings may tighten −1% to −2% if they wrap too soon.

### 6.3 Platform Stacks

* **iOS:** Lora + `-apple-system` (SF) fallback; Source Sans 3 (or SF) for body.
* **Android:** Lora + Roboto fallback; Source Sans 3 or Roboto for body.
* **Web/RN:** `"Lora", serif` for headings; `"Source Sans 3", system-ui, sans-serif` for body.
* **Numbers:** `font-variant-numeric: tabular-nums;` (or platform equivalent).

---

## 7) Components

### 7.1 Buttons (replace all grey HTML blocks)

**Shape:** 12 px radius. **Padding:** 10–12 px vertical, 16–20 px horizontal.
**States:** Hover darken ~10%; Active slight press; Disabled 40% opacity; Focus outline 2 px.

* **Primary (solid carrot):**

  * Fill `#E77C1F`, Label `#FFFFFF`.
  * Use for the main call-to-action on a screen (e.g., “Log Meal”).

* **Secondary (ghost lettuce):**

  * Transparent fill, **1.5 px** border `#6FBF4A`, Label `#183A2E`.
  * Use for supportive actions (e.g., “Scan”).

* **Tertiary (solid beetroot):**

  * Fill `#8E2043`, Label `#FFFFFF`.
  * Use sparingly for emphasis and iron/supplement flows (e.g., “Add Iron Supplement”, iron chips).

### 7.2 Cards / Sheets

* Surface `#FFFFFF`; 1 px border `#E0EAE0`; **no heavy shadow** (≤2dp if any).
* Radius 12 px.
* Titles in Lora; body in Source Sans 3.

### 7.3 Chips / Badges

* **Iron emphasis:** Solid beetroot + white text.
* **Vitamin C / Positive:** Outlined lettuce (transparent fill, lettuce border, deep label).
* Provide an “inverse” info variant: very light beet tint + beet text.

### 7.4 Progress

* Track: `#E6EEE6`; Fill: lettuce `#6FBF4A`.

### 7.5 Tabs / Nav

* On Herb Tint background: deep text `#183A2E`; active state uses lettuce underline/dot; avoid full-bleed accent bars.

---

## 8) Layout & Spacing

* Increase vertical rhythm a notch on the lighter bg (e.g., 12→16 px between modules).
* Prefer separation by **borders and spacing** instead of shadows.
* Keep corner radii consistent (12 px) across cards and buttons.

---

## 9) Accessibility (non-negotiable)

* **Body text contrast:** ≥ 4.5:1 (prefer ≥ 7:1 on Herb Tint).
* **Large headers:** ≥ 3:1.
* **Buttons:** label vs fill ≥ 4.5:1.
* **Focus visible** everywhere, keyboard and screen readers included.
* **Color-blind resilience:** carrot vs lettuce actions distinguishable by labels/icons, not color alone.

## 10) Implementation Snippets

### Web / RN-Web (CSS variables)

```css
:root{
  --bg:#F7FBF7; --surface:#FFFFFF; --hair:#E0EAE0; --text:#183A2E;
  --carrot:#E77C1F; --lettuce:#6FBF4A; --beet:#8E2043; --quiet:#B6915E;
}
html,body{ background:var(--bg); color:var(--text); font-variant-numeric:tabular-nums; }

.card{ background:var(--surface); border:1px solid var(--hair); border-radius:12px; box-shadow:none; }

button{ appearance:none; background:none; border:0; font:inherit; cursor:pointer; border-radius:12px; }
.btn--primary{ background:var(--carrot); color:#fff; padding:10px 16px; }
.btn--secondary{ background:transparent; border:1.5px solid var(--lettuce); color:var(--text); padding:9px 15px; }
.btn--tertiary{ background:var(--beet); color:#fff; padding:10px 16px; }

.btn--primary:hover,.btn--tertiary:hover{ filter:brightness(0.9); }
.btn--secondary:hover{ border-color:#5AA83F; }
button:focus-visible{ outline:2px solid #183A2E; outline-offset:2px; }
button:disabled{ opacity:.4; cursor:not-allowed; }
```

### SwiftUI

```swift
// Colors
let bgApp = Color(hex:"#F7FBF7")
let surface = Color.white
let hair = Color(hex:"#E0EAE0")
let textPrimary = Color(hex:"#183A2E")
let carrot = Color(hex:"#E77C1F")
let lettuce = Color(hex:"#6FBF4A")
let beet = Color(hex:"#8E2043")

// Card
RoundedRectangle(cornerRadius:12)
  .fill(surface)
  .overlay(RoundedRectangle(cornerRadius:12).stroke(hair, lineWidth:1))
  .shadow(radius:0)

// Buttons
struct PrimaryButton: View {
  var title:String
  var body: some View {
    Text(title).font(.system(size:16, weight:.semibold))
      .foregroundColor(.white)
      .padding(.vertical,10).padding(.horizontal,16)
      .background(RoundedRectangle(cornerRadius:12).fill(carrot))
  }
}
struct SecondaryButton: View {
  var title:String
  var body: some View {
    Text(title).font(.system(size:16, weight:.semibold))
      .foregroundColor(textPrimary)
      .padding(.vertical,9).padding(.horizontal,15)
      .overlay(RoundedRectangle(cornerRadius:12).stroke(lettuce, lineWidth:1.5))
  }
}
```

* All text/buttons meet AA contrast thresholds.

---

## 13) Risks & Mitigations

* **Serif everywhere degrades readability on low-end Android.**
  *Mitigation:* Lora only for headings/tips; body in Source Sans 3/Inter; body size ≥16–17.
* **Overuse of accents → garish.**
  *Mitigation:* Enforce usage budget; lint during review.
* **Contrast regressions with Herb Tint.**
  *Mitigation:* Automated checks + manual QA; increase weight/size before color changes.
